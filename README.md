# Обновления «Селены»

Канал APK-обновлений «Селены». Приложение в канале **sideload** при запуске читает
`updates.json` и предлагает обновиться, если `versionCode` выше установленного.

- Основное приложение — **`com.seluk.selena`**. Его sideload-сборки обновляются через этот
  репозиторий; теги релизов — `selena-v<versionCode>`.
- Сборка **Play** имеет тот же package `com.seluk.selena`, но `SELF_UPDATE=false`:
  этот канал она не проверяет, обновления получает через Google Play. Поведение определяется
  каналом сборки, а не только именем пакета.
- `updates.json` содержит отдельную запись для каждого applicationId. Записи старых приложений
  `com.seluk.selena.family` и `com.seluk.healthdiary` сохранены для прежних установок;
  их версии заморожены, новые выпуски единой программы в эти записи не помещаются.
- APK размещаются файлами в [релизах](../../releases).

формат может содержать только базу без вложений; сохраняйте старое приложение и оригиналы
файлов до проверки переноса.

## Как выпустить обновление

1. Собрать подписанный **sideload release APK** с пакетом `com.seluk.selena` и новым,
   увеличенным `versionCode`. Проверить версию и подпись: обновление должно быть совместимо
   с подписью предыдущего APK этого пакета. Debug, unsigned и Play-сборки сюда не публикуются.
2. Создать релиз `selena-v<versionCode>` и приложить окончательный APK. Для текущего выпуска
   используется тег `selena-v8`. Убедиться, что релиз и файл доступны публично.
3. Скачать опубликованный файл и сверить его размер и SHA-256 с исходным APK.
4. Только после проверки файла обновить в `main/updates.json` запись **`com.seluk.selena`**:
   `versionCode`, `versionName`, `apkUrl`, `sha256` (64 символа, нижний регистр), `sizeBytes`
   (число байт), `notes` (короткое «что нового» для диалога). Сохранить остальные записи.
   JSON сохраняется в UTF-8; `apkUrl` указывает на постоянный HTTPS-адрес файла релиза GitHub.
5. Проверить публичный `updates.json`, ссылку на APK и таблицу релизов в этом README.
   Изменённый APK выпускается с новым `versionCode`, а не заменяет файл уже опубликованной версии.

Целостность файла приложение проверяет по sha256, подлинность — подпись APK проверяет
сам Android (APK с чужим ключом поверх установленного не встанет).

Исходный код приложения — в приватных репозиториях; здесь только артефакты обновлений.
