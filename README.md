# Обновления «Селены»

Служебный репозиторий: приложение «Селена» (sideload-издания без магазина) при входе читает
`updates.json` и предлагает обновиться, если там номер версии выше установленного.

- `updates.json` — манифест: ключ — applicationId издания
  (`com.seluk.selena.family` — семейная, `com.seluk.healthdiary` — персональная).
- APK лежат ассетами в [релизах](../../releases); теги — `family-vN` / `personal-vN`
  по versionCode.
- Универсальная редакция (`com.seluk.selena`, Google Play) через этот канал **не** обновляется:
  самообновление мимо магазина запрещено политикой Play, проверка канала в ней отключена.
  Её обновления — только через Google Play.

## Как выпустить обновление

1. Собрать подписанный release-APK (versionCode поднять!).
2. Создать релиз с тегом `family-v<versionCode>` (или `personal-v<versionCode>`),
   приложить APK ассетом.
3. Обновить в `updates.json` запись издания: versionCode, versionName, apkUrl,
   sha256 (нижний регистр), sizeBytes, notes (короткое «что нового» — попадает в диалог).

Технические заметки (Windows): `gh` CLI не установлен — релиз и `updates.json` заводятся через
GitHub API с токеном из `git credential fill`; `curl.exe` нужен ключ `--ssl-no-revoke`
(иначе schannel `CRYPT_E_NO_REVOCATION_CHECK`); тела JSON передавать ФАЙЛАМИ в ASCII
(кириллица в аргументах `curl.exe`/`python` из git-bash перекодируется и ломает JSON).

Целостность файла приложение проверяет по sha256, подлинность — подпись APK проверяет
сам Android (APK с чужим ключом поверх установленного не встанет).

Исходный код приложения — в приватных репозиториях; здесь только артефакты обновлений.
